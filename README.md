# DUNGEON ARENA

Кооперативная игра-выживание в подземелье: отбивайтесь от волн монстров, собирайте опыт, качайте героя и выживайте как можно дольше — в одиночку или с друзьями (до 6 игроков в комнате).

Враги созданы по мотивам ассет-паков **Dungeons I–III**: слизни и летучие мыши, **скелеты** и **гоблины** (Dungeons II), гоблины-шаманы и **скелеты-рыцари** (Dungeons III), а также босс — **Некромант**, призывающий скелетов и стреляющий веером снарядами.

## Возможности

- **Волны врагов** — состав и сила врагов растут с каждой волной; каждая 5-я волна — боссовая (Некромант + свита)
- **7 типов врагов** — у каждого своё поведение: ближний бой, дальнобойные шаманы, летающие мыши с хаотичным движением, танки-рыцари, призывающий босс
- **Система прокачки** — опыт падает с врагов (гемы), при новом уровне выбор 1 из 3 случайных усилений: урон, скорость атаки, залп, пробивание, броня, вампиризм, крит, регенерация, магнетизм и др. (12 усилений с уровнями стеков)
- **Мультиплеер (кооп)** — комнаты по коду из 4 символов, общий бой, список игроков, возрождение павших товарищей через 20 секунд
- **Таблица лидеров** — результаты забегов сохраняются в SQLite (Prisma)
- **Пиксель-арт** — спрайты нарисованы процедурно (матрицы пикселей), анимация в 2 кадра, вспышки урона, частицы, всплывающие числа
- **Звук** — синтезированный на WebAudio, без аудиофайлов
- **Мобильное управление** — виртуальный джойстик слева, тап справа — рывок

## Управление

| Действие | ПК | Телефон |
|---|---|---|
| Движение | WASD / стрелки | джойстик (левая половина экрана) |
| Рывок | Пробел | тап по правой половине экрана |
| Атака | автоматическая | автоматическая |

## Технологии

- **Next.js 16** (App Router) + **TypeScript**
- **Canvas 2D** — игровой рендер с интерполяцией снапшотов (клиентское предсказание своего героя)
- **socket.io** — авторитарный игровой сервер (отдельный mini-service, порт 3010), 20 тиков/с
- **Prisma + SQLite** — таблица результатов
- **Tailwind CSS 4 + shadcn/ui** — меню, лобби, модалки
- **WebAudio** — процедурные звуки

## Запуск

Требуется [bun](https://bun.sh).

```bash
# 1. Зависимости
bun install

# 2. База данных (SQLite + Prisma)
cp .env.example .env
bun run db:push

# 3. Игровой сервер (socket.io, порт 3010)
cd mini-services/game-server && bun install && bun run dev &

# 4. Веб-приложение (порт 3000)
bun run dev
```

Откройте http://localhost:3000 — одиночный забег или комната с друзьями.

> В облачном окружении с единым шлюзом клиент подключается к игровому серверу по относительному пути `/?XTransformPort=3010` (проксирование запросов настраивается на фронт-шлюзе).

## Структура проекта

```
src/
  app/
    page.tsx                  # входная точка — игра
    api/leaderboard/route.ts  # GET — таблица лидеров
  components/game/
    game-app.tsx              # меню, лобби, модалки прокачки/результатов
    arena.tsx                 # Canvas-движок: рендер, ввод, HUD, интерполяция
  lib/game/
    config.ts                 # общий конфиг (клиент + сервер): враги, волны, апгрейды
    sprites.ts                # пиксель-арт спрайты (матрицы + палитры)
    audio.ts                  # WebAudio-синтезатор звуков
mini-services/game-server/
  index.ts                    # авторитарный сервер: комнаты, волны, ИИ, прокачка, БД
prisma/schema.prisma          # модель GameResult
```
